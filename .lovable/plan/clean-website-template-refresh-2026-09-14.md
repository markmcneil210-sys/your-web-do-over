# Clean Website Template Refresh

## Goal
Update the public website with the selected modern minimalist direction while preserving all current content, links, event details, statistics, sign-up access, and private initiative restrictions.

## Visual direction
- Use the selected Charcoal & Ember palette: `#1a1a1a`, `#2d2d2d`, `#4a4a4a`, and `#e85d3a` through the site’s shared color system.
- Use Instrument Serif for headings and Work Sans for body text.
- Organize the homepage as clean, full-width sections with generous spacing, restrained corners, and strong contrast.
- Rework the opening area into a modern minimalist composition using the existing community photograph and existing calls to action.

## Homepage updates
- Simplify the header and navigation, including a practical mobile menu.
- Refresh the opening section, mission, impact statistics, programs, team, vision, events, and footer into one cohesive style.
- Replace emoji-style decoration with clear icons where needed.
- Keep the current July 9, 2026 flyer fully visible and preserve event media.
- Keep all existing pages and authentication behavior available.

## Quality checks
- Verify the homepage at desktop and mobile sizes.
- Check that navigation, sign-up, login, and initiative links remain usable.
- Confirm headings, images, and text do not overlap or crop unexpectedly.
- Confirm the site builds without errors.

## Technical details
- Update shared theme colors and typography in the global design system.
- Refine the existing homepage sections rather than replacing business logic or database behavior.
- Update page title and description so they identify Rebuild Networking and Athletes Economic Alliance.
